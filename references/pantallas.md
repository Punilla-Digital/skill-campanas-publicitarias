# Pantallas y actualización

Mantener mapa semántico orientativo, no coordenadas ni promesas de menús fijos:
- GTM: espacio de trabajo; etiquetas; activadores; variables; vista previa; versiones/publicación.
- GA4: administración de propiedad/flujo, eventos/eventos clave, DebugView, vinculaciones.
- Ads: objetivos/conversiones, campañas, grupos, anuncios, recursos, configuración.
- Meta: Administrador de eventos, datos/eventos de prueba/diagnósticos; Commerce Manager/catálogos/orígenes de datos.

Verificar ruta exacta ante cada ocasión con captura actual o fuente oficial. La interfaz puede variar por idioma, permisos, tipo de cuenta y despliegue. No usar rutas históricas como certeza.

Al aprender una pantalla, registrar durante la sesión: plataforma, fecha, idioma, ruta observada, campos visibles, opciones elegidas, evidencia y limitaciones. Para guardar aprendizaje permanente, actualizar esta referencia mediante skill-creator cuando el usuario lo pida: describir qué cambio es general, citar fuente oficial y fecha de verificación, preservar variantes y retirar pasos obsoletos. No almacenar credenciales ni IDs de clientes como valores predeterminados.

Ejemplos de uso:
- “Estoy en configuración de etiqueta. Decime título y campos.”
- “Instalamos GTM en WordPress; guiame para medir WhatsApp.”
- “Creemos campaña de búsqueda para seguros con presupuesto confirmado.”
- “Esta pantalla de Meta cambió; actualizá la skill según estas capturas.”
